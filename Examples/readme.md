# Examples — XD-M Motor Controller

This folder contains example code and projects for controlling an **XD-M motor controller**, organized by language/platform:

| Folder | Language | Description |
|--------|----------|-------------|
| [`Python/`](Python/readme.md) | Python | USB (library) example for controlling the XD-M, using the `Xeryon.py` library. |
| [`CPP/`](CPP/readme.md) | C++ | USB (library) example for controlling the XD-M, using a cross-platform C++ SDK. |
| [`LabVIEW/`](LabVIEW/readme.md) | LabVIEW | A full LabVIEW project (axis driver, sequencer, preferences) for controlling multiple XD-M axes from a LabVIEW application. |

> [!NOTE]
> All folders control the same XD-M controller, but use different languages. See the readme inside each folder for setup and usage details before running anything.

## Which one do I need?

- Using Python on a PC → see [`Python/readme.md`](Python/readme.md).
- Using C++ on a PC → see [`CPP/readme.md`](CPP/readme.md).
- Using LabVIEW → see [`LabVIEW/readme.md`](LabVIEW/readme.md).
