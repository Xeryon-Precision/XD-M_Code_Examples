# XD-M Motor Controller

This folder contains the manual and example code for the **XD-M motor controller**.

| Folder | Description |
|--------|-------------|
| [`Docs/`](Docs/) | The XD-M product manual (`Xeryon XD-M manual v3.2.pdf`). |
| [`Examples/`](Examples/readme.md) | Example code and projects for controlling the XD-M, organized by language/platform — Python, C++, and LabVIEW. |

> [!TIP]
> Start with [`Docs/Xeryon XD-M manual v3.2.pdf`](<Docs/Xeryon XD-M manual v3.2.pdf>) for hardware setup and wiring, then see [`Examples/readme.md`](Examples/readme.md) to pick the language/platform matching your setup.
